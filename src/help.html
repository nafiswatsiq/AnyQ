ANYQ GUIDE

Hotkeys & Quick Help

Gunakan shortcut berikut untuk mengontrol overlay tanpa berpindah dari aplikasi yang sedang digunakan.

Hotkeys

Ctrl+Shift+Space
Toggle click-throughMengaktifkan atau menonaktifkan interaksi mouse pada overlay.
Ctrl+Shift+S
Screenshot → AIMengambil screenshot monitor tempat kursor berada lalu mengirimnya ke Chat model.
Ctrl+Shift+A
Record audio → AIMerekam microphone atau system audio sesuai pilihan di Settings.
Ctrl+Shift+I
Focus chat inputMenampilkan overlay dan memfokuskan input pertanyaan.
Ctrl+Shift+H
Show / hide overlayMenyembunyikan atau menampilkan overlay.
Ctrl+Shift+Q
Quit AnyQMenutup aplikasi AnyQ sepenuhnya.
Esc
Cancel AI responseMenghentikan response AI yang sedang streaming.

Chat teks

Tekan Ctrl + Shift + I, tulis pertanyaan, lalu tekan Enter. Gunakan Shift + Enter untuk baris baru.

Drag window

Saat click-through OFF, seret area header untuk memindahkan overlay. Saat ON, overlay meneruskan klik ke aplikasi di belakangnya.

Input audio

Pilih Microphone untuk suara mic atau System audio untuk suara speaker/headset di Settings. Tekan Ctrl + Shift + A untuk mulai dan tekan lagi untuk berhenti.
